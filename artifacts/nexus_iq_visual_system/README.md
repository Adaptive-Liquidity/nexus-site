# Nexus-IQ Visual Systems Concept Lab

A self-contained, deterministic concept package for product-native Nexus-IQ visuals.

## Included

- `nexus-iq-visual-concept-lab.html` — interactive browser lab with no external dependencies or network requests.
- `nexus-iq-visual-systems-blueprint.md` — route-by-route audit, visual system, implementation architecture, PBR pipeline, QA rubric, and production sequence.
- `exports/` — five editable SVG diagrams and 1600×900 PNG review exports:
  1. Cognitive Hypervisor
  2. Causal Control Trace
  3. Three-System Architecture Atlas
  4. Proof Capsule Evidence Lattice
  5. Adversarial Trust Boundary

## Run

Open `nexus-iq-visual-concept-lab.html` directly in a modern browser.

## Scope

This is a design prototype, not repository code and not a product maturity claim. It is intentionally built from semantic SVG/HTML rather than generated cinematic scenery. It does not modify, commit, push, deploy, or change claims in the Nexus-IQ repository.
