Primary views

Distribution first for microbenchmarks; scaling curves for state-size-dependent operations; commit deltas only with uncertainty and runner parity.

Public honesty

The workbench may show current CI data, but must retain the site’s rule: no number is promoted without methodology, environment, and maturity context.

Production data contract: immutable benchmark artifact → schema validation → derived plots. The UI must never scrape prose or manually transcribe headline values.

    Interactive truthfulness
    Paths that are not live are labeled “fixture simulation” or “In Integration.” The simulator never implies it intercepted a real model tool decision.
    High-value perturbations
    Expire a token, fail a validator, degrade memory attestation, or introduce an external side effect; then compare state, decision, and receipt fields.
    Best integration: preserve this simulator beside concrete repository links and copyable schemas. It teaches the contract while the source remains the authority.
    

    


    P1 visual doctrine
    Relationships are the visual system.
    These instruments make Nexus-IQ feel advanced by exposing real dependency, authority, measurement, and evidence mechanics—not by placing technical copy inside decorative science-fiction imagery.
    Prototype status
    All data in the benchmark and integration instruments is explicitly representative. The graph and topology are grounded in the current public claims registry but remain design studies until wired to canonical data in the repository.
